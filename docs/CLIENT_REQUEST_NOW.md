## 0. 지금 상태 한 줄

화면은 **이미 만들어져 있고**, 값이 비어 있다.
그래서 이 요청서는 "무엇을 만들까요"가 아니라 **"빈칸을 채워 주세요"** 다.

| | 만들어진 것 | 비어 있는 것 |
| --- | --- | --- |
| 메인 | 히어로 · 제품 줄 · 브랜드 주장 · 핏 비교 · 사이즈 찾기 · 교환 안내 | 제품명 · 가격 · 실측 수치 |
| 제품 목록 | 카드 · 필터(핏/카테고리/사이즈/재고) | 제품 정보 전부 |
| 제품 상세 | 갤러리 · 실측표 · 모델정보 · 고시표 · 구매 패널 | 같음 |

## 1순위 — 이게 없으면 **설계가 멈춘다** (3개)

### ① 사이트에서 결제까지 하나요? `A-1`

- ㉠ **결제까지 한다** (장바구니 → 주문 → 결제 → 배송조회 → 교환신청)
- ㉡ **카탈로그 + 문의만** (제품은 다 보여주고, 구매는 전화·카톡·인스타로)

**왜 먼저 필요한가**: ㉡이면 **페이지 약 15개가 통째로 빠진다**(장바구니·결제·주문내역·교환신청 등).
서버도 주문/결제 도메인 전체가 필요 없어진다. 지금 만들면 버리는 작업이 된다.

### ② 사이즈를 뭐라고 부르나요? `B-3`

- ㉠ `95 / 100 / 105 / 110` ㉡ `S / M / L / XL` ㉢ 그 외 (알려주세요)

**왜**: 이 이름이 상품 등록 단위(SKU)·필터·사이즈 선택 버튼에 전부 박힌다. 나중에 바꾸면 데이터를 다시 넣어야 한다.

### ③ 사이즈별 실측 수치 `B-4` ← **이 사이트의 존재 이유**

상품마다 사이즈별로 **어깨 · 가슴 · 허리 · 소매 · 총장** (cm).
그리고 두 가지를 꼭 함께:

- **재는 기준**: 평평히 놓고 잰 **단면**인가, 한 바퀴 두른 **둘레**인가 → 값이 2배 차이로 읽힌다
- **허용 오차**: 예) ±1cm

**보내는 방법**: 엑셀·구글시트 한 장이면 됩니다. 손으로 적은 사진도 괜찮습니다.

```
사이즈  어깨   가슴   허리   소매   총장
95     43.0  100.0  92.0  60.5  72.0
100    44.5  104.0  96.0  61.5  73.5
```

> 지금 **실측표 · 핏 비교표 · 사이즈 찾기 계산기** 세 화면이 이 값을 기다리며 비어 있습니다.
> 값을 지어내지 않았습니다 — 틀린 치수는 그대로 교환 CS가 되기 때문입니다.

## 못 받아도 멈추지는 않습니다

값이 없어도 진행할 수 있게 만들어 뒀습니다:

- 비어 있는 값은 **화면에 "확인 중"으로 표시**됩니다 — 잊히지 않습니다
- 가격이 없으면 **"가격 문의"**로 나옵니다 → ①이 ㉡으로 정해져도 그대로 정상 화면이 됩니다
- 실측값이 들어오면 **표가 저절로 채워집니다** — 화면을 다시 만들지 않습니다

다만 **1순위 ①(판매 범위)** 만은 예외입니다. 이건 만들 페이지의 개수 자체를 바꾸므로,
답이 늦어질수록 나중에 버리는 작업이 늘어납니다.
